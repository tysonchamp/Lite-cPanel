Setup in GitHub or GitLab
  1. Go to your Repository on GitHub or GitLab.
  2. Navigate to Settings → Webhooks → Add Webhook.
  3. Paste the Webhook Payload URL above.
  4. Select application/json as the Content type.
  5. Paste the Webhook Secret into the Secret field.
  6. Choose Just the push event and save. Lite-cPanel will now auto-deploy on every push!
